# ChatGPT 提问导航

**对话再长，也能找回前面那个问题。**

为 ChatGPT 长对话添加独立的提问导航栏。悬停查看问题预览，点击回到对应消息；不用反复拖滚动条、在大量回答中寻找。

![交互示意](docs/overview.svg)

## 为什么需要它？

长对话往往包含多个问题和多轮追问。原始聊天按时间铺开，回头找某个问题容易打断思路。本扩展把已读取的用户消息整理为可点击目录，保留页面原有聊天功能。

- **快速回到问题**：按消息标识定位，确认命中后才报告成功。
- **近期内容先可用**：默认尝试预加载最近 10 条用户消息，可设置 0–200。
- **越读越完整**：手动浏览历史时继续收集，也可主动向前收集。
- **用完就收起**：一键展开 / 收起，保留小入口；收起不清空目录，记住开合状态。
- **附件消息也能导航**：能读到文件名时显示附件名称。

## 安装

1. 点击 **Code → Download ZIP**，解压。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压目录里的 **`extension` 文件夹**（包含 `manifest.json`）。
5. 刷新已有 ChatGPT 标签页，打开一段已有对话，右侧出现导航栏。

这是可直接加载的独立扩展，**尚未上架扩展商店**。如果曾安装同类用户脚本，先停用，避免重复导航栏；旧脚本的设置不会迁移。

## 怎么用？

| 操作 | 效果 |
| --- | --- |
| 鼠标停在右侧短线上 | 查看对应问题的预览 |
| 点击短线 | 定位该条用户消息 |
| 点击“收起” / “展开” | 隐藏 / 恢复整个目录；保留已记录条目 |
| 点击“导” | 打开工具面板 |
| 修改条数并保存 | 设置下次进入对话的近期预加载目标；0 关闭自动加载 |
| 补齐最近 | 从最近内容开始尝试补齐预加载目标 |
| 向前收集 | 向上滚动并继续建立目录 |
| Esc 或“停止” | 中止正在进行的自动滚动 |
| 回到底部 | 返回当前对话底部 |
| 清空重建 | 从当前页面重新记录目录 |

你开始手动滚动或操作页面时，自动滚动会停止，避免与阅读争夺位置。收起导航也会停止当前任务。

## 数据和权限

- 只在 ChatGPT 域名上运行；仅申请本地设置存储权限。
- 本地持久保存预加载条数和开合状态。
- 聊天预览、文件名与消息标识仅保留在当前页面内存，不上传，不保存到扩展设置。
- 不调用 ChatGPT 私有接口，不读取附件内容，不需要 API Key，不使用分析统计服务。

## 当前边界

ChatGPT 会虚拟化长对话，目录只能收集页面已加载和工具实际遇到的消息，因此标注为**“已记录 · 非全量”**；目录序号不是整段对话的绝对消息编号。刷新页面会重建目录，切换对话不会沿用上一段目录。

网页结构变化可能影响采集和定位；遇到问题可先更新扩展、清空重建，再手动浏览对应位置。主页、新建空白对话不显示导航。
