# ChatGPT 提问导航

**对话再长，也能找回前面那个问题。**

![交互示意](docs/overview.svg)

## 解决什么问题？

长对话里回找问题，需要在大量回答中反复滚动。本扩展把已读取的用户提问整理成独立目录：

- **悬停预览、点击定位**，快速回到对应消息。
- **近期预加载、边读边收集**，减少手动寻找。
- **一键展开 / 收起**，保留目录和开合偏好。
- **附件消息也可导航**，能读取到文件名时显示名称。

## 怎么安装？

1. **Code → Download ZIP**，解压。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式” → “加载解压缩的扩展”。
4. 选择解压目录里的 **`extension` 文件夹**，刷新 ChatGPT 页面。

独立浏览器扩展，无需篡改猴；尚未上架商店。安装前停用旧版同类脚本，避免重复运行。

## 怎么用？

| 操作 | 效果 |
| --- | --- |
| 悬停右侧短线 | 看问题预览 |
| 点击短线 | 回到对应提问 |
| 点击“收起” / “展开” | 隐藏 / 恢复目录 |
| 点击“导” | 设置预加载、向前收集、回到底部 |
| 按 Esc | 停止自动滚动 |

目录随实际读取的历史逐步增加，不保证一次加载全部消息。数据仅在本地处理，不上传聊天内容。
