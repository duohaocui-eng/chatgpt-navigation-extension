# 安装与常见问题

**选择哪个文件夹？** 选择有 `manifest.json` 的 `extension` 文件夹，不要选择仓库最外层。

**安装后没出现？** 刷新 ChatGPT 页面，进入 `/c/` 下的一段已有对话。检查旧用户脚本是否仍开启；不要同时运行两份。受组织管理的浏览器可能禁止加载未上架扩展。

**为什么目录只有几条？** ChatGPT 不一次加载所有历史。默认目标是最近 10 条用户消息，可以在“导”里设置；这个目标不是目录上限。

**收起后还能找回来吗？** 右上区域保留“展开”按钮。目录仍在，刷新前不用重新收集；刷新后只保留开合状态和预加载设置，消息目录会重建。

**点击后为什么等待？** 已记录消息可能已从当前页面卸载，需要滚动重新加载并核验。按 Esc 可中止。没有找到目标时会明确提示，不把缓存坐标当作成功定位。

**输入框里有文字时会自动滚动吗？** 工具会尽力检测草稿、生成状态和历史阅读位置，避免不合时宜的预加载；也可把预加载条数设为 0。

**Work 页也支持吗？** 扩展运行于 ChatGPT 对话页面；仅在存在当前支持的用户消息标识和滚动区域时工作。特殊布局或后续网页更新需实际确认。

**如何更新？** 下载新版本替换原文件夹内容，在扩展管理页点击该扩展的重新加载按钮，再刷新 ChatGPT 页面。

**如何卸载？** 在扩展管理页移除即可。没有向 ChatGPT 账号写入任何设置。
