# 数据与兼容说明

扩展仅在 ChatGPT 域名运行，申请本地设置存储权限。持久保存预加载条数与开合状态；聊天预览、文件名和消息标识只留在当前页面内存，不上传。

不调用私有接口，不解析附件内容，不需要 API Key。刷新后重新建立消息目录，切换对话清空旧目录。

ChatGPT 会虚拟化长对话，目录只包含实际读取到的用户消息；“已记录”的序号不是全对话绝对序号。网页结构变化、特殊布局可能影响兼容性，无法定位时可清空重建并手动浏览相邻位置。

安装后需要刷新原有 ChatGPT 页面。当前版本已通过模拟页面检查，实际浏览器长对话兼容性仍需使用验证。更多见 [使用说明](USAGE.md)。
